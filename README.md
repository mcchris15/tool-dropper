Reads file `tool_heights.txt`, subtracts 0.03 from each value, then saves the file along with a backup of the original.  

##How to Use

File must be named `tool_heights.txt` and placed in the same directory as `tool-dropper.ps1`.  

Tool list must be formatted as:  

_First Tool Name_: ##.####  

_Second Tool Name_: ##.####  

_etc._
